# ShardX Extension

Наше фірмове розширення <mark style="color:purple;">**ShardX – Smart Proxy Manager**</mark> встановлюється в Opera безпосередньо з **Chrome Web Store**.

## Встановлення

Відкрийте сторінку розширення та натисніть кнопку встановлення. Якщо Opera попросить підтвердити встановлення з Chrome Web Store, надайте дозвіл.
