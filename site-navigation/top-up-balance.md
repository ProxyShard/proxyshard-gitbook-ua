# Поповнення балансу

Баланс використовується для придбання продуктів, продовження замовлень та оплати додаткового трафіку. Мінімальна сума поповнення становить **$5**.

Щоб поповнити баланс:

1. Відкрийте розділ [`Wallet`](https://dashboard.shardx.com/en/wallet).
2. Вкажіть суму в полі `Top up balance amount`.
3. Виберіть спосіб оплати в полі `Payment method`.
4. Натисніть `Top up your balance` і завершіть оплату.

У списку `Payment method` доступні:

* `Credit Card / Google Pay` - оплата банківською карткою або через Google Pay. Платіж обробляється через Stripe.
* `Nowpayments (Crypto)` - оплата криптовалютою.
* `USDT TRC20` - окремий спосіб оплати USDT у мережі TRC20 (TRON).

{% hint style="warning" %}
Для оплати USDT у мережі TRC20 виберіть саме `USDT TRC20`. Платіжна система стягує відсоткову комісію, тому мінімальна сума такого платежу становить **$21**.
{% endhint %}

У блоці `History` відображаються сума, статус і дата кожного поповнення. Натисніть `Open`, щоб відкрити рахунок і за потреби завантажити його у форматі PDF.
