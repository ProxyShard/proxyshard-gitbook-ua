# Обмеження

На цій сторінці перелічені всі чинні обмеження щодо наших продуктів.

***

## Блокування окремих сайтів

Через проксі недоступні:

* Банківські сайти (онлайн-банкінг, особисті кабінети банків)
* Державні портали та сайти, а також сайти в доменних зонах `.gov` і `.edu`
* Платіжні процесори: <mark style="color:purple;">Stripe</mark>, <mark style="color:purple;">PayPal</mark> (у тому числі <mark style="color:purple;">Yahoo</mark>)

Це вимога регуляторів, спрямована на запобігання шахрайству. Блокування **не поширюється** на криптосервіси та платіжні системи на кшталт бірж.

{% hint style="warning" %}
Стосується всіх продуктів, **крім** [Mobile proxy](mobile-proxies.md).

Stripe і PayPal доступні на датацентрових та ISP-проксі.
{% endhint %}

Додаткові обмеження на резидентських проксі:

* На [Standard Residential](residential-proxies/standard-residential.md) / [Unlimited Residential](residential-proxies/unlimited-residential-proxy.md) / [Premium Residential](residential-proxies/premium-residential.md) недоступні сервіси Microsoft та Apple.

## UDP на резидентських проксі

{% hint style="danger" %}
UDP не працює на [Standard Residential](residential-proxies/standard-residential.md) і [Unlimited Residential](residential-proxies/unlimited-residential-proxy.md) у локації **US** :flag\_us:
{% endhint %}

Це не наше обмеження. На початку 2026 провайдери в США заборонили вхідні UDP-з'єднання без попередньої ініціації зсередини мережі. Через це UDP Associate на проксі перестав працювати у цьому регіоні.

На інших локаціях Standard і Unlimited підтримують UDP з урахуванням загальних обмежень портів.

На [Premium Residential](residential-proxies/premium-residential.md) UDP доступний у всіх локаціях, крім окремих міст і пристроїв на базі macOS/iOS.

### Обмеження UDP-портів для Standard та Unlimited

Для Standard та Unlimited тимчасово дозволено UDP-трафік лише на цільові порти `8443`, `8080`, `3478` і `19302`. Решта діапазонів UDP-портів заблоковані. У локації США UDP, як і раніше, повністю недоступний.

Для Premium Residential цього обмеження портів немає. Для Premium продовжують діяти лише винятки для окремих міст і пристроїв macOS/iOS.

### `static_mode2` і пристрої macOS/iOS

`static_mode2` відповідає значенню `Static` у полі `Session mode` для Premium Residential. У цьому режимі проксі утримує вибраний пристрій і не перемикає сесію на інший пристрій, якщо поточний тимчасово виходить із мережі.

Якщо вибраний пристрій недоступний, рядок проксі може перестати відповідати до його повернення або завершення `TTL`. Щоб одразу отримати інший пристрій, створіть новий рядок через `Generate proxy`.

Фільтр `Device OS: macOS` або `iOS` суттєво скорочує доступний пул. Якщо одночасно вибрати місто й провайдера, відповідних пристроїв може не бути, особливо в країнах Tier 2 і Tier 3. UDP також недоступний на частині пристроїв macOS/iOS і в окремих містах.

## Підміна p0f на мобільних проксі

Підміна відбитка пристрою (p0f) недоступна для деяких країн і операторів:

| Країна                    | Оператор        |
| ------------------------- | --------------- |
| Великобританія :flag\_gb: | Усі оператори   |
| Ірландія :flag\_ie:       | Vodafone        |
| Німеччина :flag\_de:      | Усі оператори   |
| Нідерланди :flag\_nl:     | Vodafone        |
| Франція :flag\_fr:        | Усі оператори   |
| Італія :flag\_it:         | Vodafone, WIND  |
| Польща :flag\_pl:         | Orange          |
| Індонезія :flag\_id:      | Усі оператори   |
| Нова Зеландія :flag\_nz:  | OneNZ           |
| Україна :flag\_ua:        | Life (Lifecell) |

В усіх інших локаціях та в інших операторів підміна p0f працює у штатному режимі.

## Ліміт підключень на DC та ISP проксі

Для [датацентрових проксі](datacenter-proxies.md) та [ISP-проксі](isp-proxies.md) діє ліміт: **2 500 підключень на один IP**.

## Закриті порти

{% hint style="info" %}
Стосується всіх продуктів.
IMAP (993) доступний на датацентрових та ISP-проксі.
{% endhint %}

Через проксі заблоковані з'єднання зі службовими портами, які часто використовуються для атак на сторонні сервіси:

| Порт | Протокол |
| ---- | -------- |
| 21   | FTP      |
| 22   | SSH      |
| 23   | Telnet   |
| 25   | SMTP     |
